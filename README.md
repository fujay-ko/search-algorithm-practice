# 搜尋演算法互動練習

國中資訊課「循序搜尋」與「二分搜尋法」互動練習網頁（純靜態 HTML＋JS，無需建置）。

學生入口：`index.html`（含建議學習順序）。

---

## 正式版頁面

| 頁面 | 說明 | 適合時機 |
|------|------|----------|
| [循序搜尋練習](practice/linear_practice.html) | 選擇題互動，一格一格比對；有自動演示、預測、最壞情況挑戰 | 初學，建立基本概念 |
| [二分搜尋 v1](practice/binary_v1.html) | 選擇題：往左、往右、找到了；有自動/手動模式 | 初學，理解方向判斷 |
| [二分搜尋 v3](practice/binary_v3.html) | 五步填空：確認邊界→計算mid→判斷方向→選邊界→填索引；有錯誤分析 | 有基礎，驗證理解 |
| [循序搜尋測驗](quiz/quiz_linear.html) | 5 題難度分級，成績送 Google Sheet | 老師指定才開放 |
| [二分搜尋填空計時測驗](quiz/quiz_binary_v3.html) | 五步填空＋每題計時，成績送 Google Sheet | 老師指定才開放 |

其他舊版／備份檔已移至 `_archive/`（封存，不再被引用）。

## 測驗設定（老師）

### 1. 部署成績收集（Google Apps Script）

1. 開啟 [Google Sheet](https://sheets.google.com)，建立新的試算表
2. 點上方選單「擴充功能」→「Apps Script」
3. 把 [`gas/gas_script.js`](gas/gas_script.js) 的內容貼上，取代原本內容
4. 點「部署」→「新增部署作業」
   - 類型：**網路應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 點「部署」，複製產生的網址
6. 把網址貼入測驗頁面頂部的 `GAS_URL`：

```javascript
const GAS_URL = '貼上你的網址';
```

腳本會依測驗類型自動分工作表寫入，並以 `attemptId` 去重（學生重送不會產生重複列）。
新版另支援 `?action=stats` 聚合統計（給 `teacher.html` 儀表板用）與「切頁次數」欄位。

### 1b. 教師儀表板（選用，需部署新版腳本）

1. 依上面步驟部署**新版** `gas/gas_script.js`（舊部署不支援統計端點）。
2. 開啟 [`teacher.html`](teacher.html)，填入 GAS 網址並自訂密碼後按「載入統計」。
3. 可看到：各測驗作答人次／平均分、各步驟累計錯誤、切頁次數名單、最近 10 筆。

注意：儀表板密碼只擋學生隨手點開（存在瀏覽器本機），正式成績以試算表權限控管為準。

### 2. 測驗參數

- `quiz/quiz_binary_v3.html`：頁面底部有隱藏的老師專用參數（題數 `qTot`、每步最多答錯 `qMW`），直接改 `selected` 預設值即可；搜尋方式 `qST` 請保持 `binary`（本頁僅支援二分搜尋填空計分）。
- `quiz/quiz_linear.html`：固定 5 題、每步最多答錯 2 次、循序搜尋。

### 3. 成績送出機制

- 每次測驗產生唯一 `attemptId`；送出成功後記入本機已送清單，不重複送出。
- 測驗進行中切換分頁／隱藏視窗會累計「切頁次數」（`tabBlur`），隨成績送出並列入備用複製文字，供老師參考；總計時採 Date 基準，切頁時間照計。
- 送出失敗會存入本機待送佇列，下次開啟測驗頁自動補送；仍失敗則提供「複製成績文字交給老師」備案。
- 技術限制：送出使用 `no-cors`，瀏覽器讀不到伺服器回應，去重一律在 GAS 端完成。
- 提醒：分數在瀏覽器端計算，僅供平時練習參考；正式成績請以課堂評量為主。

## 計分說明

### 循序搜尋測驗（`quiz_linear.html`）

每題滿分 100（結果 60 分＋步驟正確率 40 分），總分取平均：

| 情況 | 結果分 | 步驟分 |
|------|--------|--------|
| 無跳過、正確找到或正確確認不存在 | 60 | `步驟數/(步驟數+答錯數) × 40` |
| 有找到但曾跳過 | 45 | 同上 |
| 未找到且有跳過 | 20 | 同上 |

### 二分搜尋填空計時測驗（`quiz_binary_v3.html`）

每題 5 步，每步滿 4 分（答錯一次扣 1 分，最低 0 分），每題 20 分，
總分正規化為 100 分制（換題數也適用）：

| 步驟 | 內容 |
|------|------|
| 確認 Left/Right | 填入目前範圍的左右索引 |
| 計算 mid | `⌊(Left+Right)/2⌋` |
| 判斷方向 | 往左／往右／找到了 |
| 選邊界 | 改 Left 或改 Right |
| 填索引 | 新的邊界值（`mid±1`） |

答錯達上限（預設 3 次）該步強制跳過（0 分）並顯示提示。

等第：A ≥ 90、B ≥ 75、C ≥ 60、D ＜ 60。

## 自動化測試（`e2e/`）

```bash
cd e2e
npm install
npx playwright install chromium
npm test
```

涵蓋：index 5 連結、兩練習頁作答流程、循序測驗完整 5 題＋離線送出→佇列→重送、
二分測驗填空第 0 步、`teacher.html` 渲染。內建零依賴靜態伺服器（`server.js`），
測試時自動啟動。

## 學生使用流程

1. 從 `index.html` 依建議順序練習（循序 → 二分選擇題 → 二分填空）。
2. 老師指定測驗版本後才開啟 `quiz/` 頁面。
3. 填寫班級、座號、姓名後開始；完成後成績自動送出，失敗時可複製成績文字交給老師。
